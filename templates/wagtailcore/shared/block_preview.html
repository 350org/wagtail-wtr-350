{% extends "wagtailcore/shared/block_preview.html" %} {% load static wagtailcore_tags %} {% comment %} Global StreamField block-preview template. Wagtail's own default (wagtail/templates/wagtailcore/shared/block_preview.html) renders the block with NO stylesheets, so every preview would come out as unstyled HTML. This override extends it and injects the site's compiled Tailwind bundle so previews render the way the block actually looks on the front end. Its mere existence is also load-bearing: Block.is_previewable only returns True for a block that has a preview value when the global preview template has been overridden (wagtail.utils.templates.template_is_overridden compares the resolved template path against the one inside the wagtail package). Delete this file and every block preview in the picker silently disappears.

Consent Mode v2 defaults — must be first.{% endcomment %} {% comment %} 2. Hold a ?form= checkout until the visitor has made a cookie choice. Fundraise Up opens a campaign's checkout as soon as its widget loads on a page whose URL carries ?form=FUNXXXXXXX (e.g. direct-ask ad links to 350.org/?form=...). Its installation snippet records location.href when it runs, at the end of , so the modal used to open on top of the Usercentrics banner, hiding its text and covering its buttons; visitors who never got to answer it left GA4, Google Ads and Meta with no data. This runs before that snippet: it takes `form` off the URL (history.replaceState, no reload) and calls FundraiseUp.openCheckout() itself once the banner is out of the way. That is the first of: - no consent needed (outside the GDPR countries, onReady below); - a choice already stored (returning visitor: __ucCmp.isConsentRequired() is false once the CMP initialises); - an explicit choice now (Usercentrics' UC_CONSENT event, or the `consent_status` EXPLICIT push it makes to the dataLayer for GTM); - the CMP not initialising within CMP_TIMEOUT_MS of page load (an ad blocker, a CDN outage): a donor is never left without the checkout. Accept and deny both count — the point is that the banner was answered. Fundraise Up puts `form` back in the URL itself while its checkout is open. {% endcomment %} {% comment %} 3. Visitor country, then load + init Usercentrics. When "Manual country override" is set on the integration (QA/local testing of a specific country), it's used directly and synchronously. Otherwise, fetch Cloudflare's built-in /cdn-cgi/trace edge endpoint (served directly by Cloudflare, never reaches Django, so this never touches the page's own edge cache or origin) and parse its "loc=XX" line for the visitor's country. Only the parsed two-letter code is ever kept -- the rest of the trace response (which also includes the visitor's raw IP address) is discarded immediately and never stored or transmitted anywhere. If the fetch fails, times out, or has no usable "loc=" line (e.g. local dev, or any environment not proxied through Cloudflare), fail closed to the configured fallback country (an EU country by default) so the compliance banner still shows rather than silently hiding it. {% endcomment %} {% endif %} {% endwith %}

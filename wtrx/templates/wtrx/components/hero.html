Expects a `hero` dict (or object) with these keys/attributes: headline — the heading text (str) copy — optional richtext value (rendered via |richtext or include_block) copy_is_block — True if copy should be rendered via include_block, False for |richtext image — optional CustomImage instance video — optional wagtailmedia Media instance (type="video") layout — "centered" (default) or "left" cta — optional HeroCTABlock stream value (0 or 1 items: signup/donate/announcement) Layout: centered or left-aligned text (hero.layout) over a full-bleed background — a video if hero.video is set, else hero.image, else plain dark background. Background video: autoplay/muted/loop/playsinline, no native controls — data-hero-video-toggle is the only playback control, custom-built instead of relying on browser-native video controls so it can sit as a small pill in the corner rather than a full control bar across a background element. No poster (browser shows first frame or black) Page templates pass `hero` via the template context (set in get_context()). HeroBlock.get_context() builds this dict automatically (video is always None there). Height: viewport height minus the site nav's height (h-16 = 4rem in header.html) when the nav is in normal flow; full viewport when the nav is transparent/overlaid (see HomePage.use_transparent_header — transparent_header is set on the page-level context and inherited here since hero.html is {% include %}'d without `only`). {% endcomment %}

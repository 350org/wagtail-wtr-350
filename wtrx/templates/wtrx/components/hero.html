Expects a `hero` dict (or object) with these keys/attributes: variant — "full" (HomePage's page-level hero only) or "banner" (every other HeroMixin page, and always for HeroBlock) headline — the heading text (str) copy — optional richtext value (rendered via |richtext or include_block) copy_is_block — True if copy should be rendered via include_block, False for |richtext image — optional CustomImage instance video — optional wagtailmedia Media instance (type="video") layout — "centered" (default) or "left". "full" variant only. banner_color — one of BACKGROUND_COLOR_CHOICES. "banner" variant only. cta — optional HeroCTABlock stream value (0 or 1 items: button/signup/donate/announcement). The "full" variant renders whichever one is set; the "banner" variant renders only the `button` choice (the embedded widgets are sized for "full"'s roomier layout and overflow banner's half-width text column) — see HeroCTABlock's docstring. tag — optional small pill label above the headline (e.g. Post's parent Blogs page title, "Blog"). "banner" variant only. Rendered as a link (back-chevron + label) to tag_url — both are set together, only by Post. tag_url — URL the tag pill links to (Post's parent Blogs page). Required whenever tag is set. author/published_at — optional, set only by Post via BannerHeroMixin's **extra (see get_banner_hero_context callers). Presence of published_at switches the "banner" variant to its compact Post styling: date above the headline at a smaller size (text-40 instead of the banner's own text-5xl) and the author name below it, per Figma's "Content Hero" instance on the Blog Post mockups vs. the larger plain instance on About/etc. variant switch: - "full": the original full-viewport hero — background video/image behind centered or left-aligned text, with a dark gradient scrim and room for a cta widget below the copy. See HeroMixin.hero_variant. - "banner": a compact rounded panel — solid color background (hero.banner_color, drawn from the shared background palette every block with a background choice uses, see main.css's .wtr-bg-{color}) on the left beside an image or video on the right, blended together with a matching-color fade (.wtr-bg-fade-{color}). Much shorter than "full", and its only cta choice is a plain link button.

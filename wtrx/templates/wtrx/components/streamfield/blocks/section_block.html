{% load i18n wagtailcore_tags %} {% comment %} value.width sets the inner content column's measure — see SECTION_WIDTH_CHOICES for why the section owns this rather than each child block. "default" (max-w-6xl, 1152px) is the historical behaviour and stays the default; "narrow" is Figma's 800px reading column for a text + accordion stack; "wide" is its 1266px media band. The heading of a section and everything under it share this one column, so a narrow accordion inside a default-width section would sit ~176px right of the heading above it — which is exactly what "Get the full picture." looked like before this field existed. {% endcomment %}
{% comment %} The max-w values are border-box (Tailwind's preflight sets box-sizing globally), so the gutters have to be counted into them for the *content* column to land on Figma's number: 1266px of video needs max-w-[1330px] against lg:px-8. "narrow" instead drops the large-screen gutter entirely — an 800px column already sits ~112px inside a 1024px viewport, so the gutter would only shave the measure without ever preventing an overflow. {% endcomment %}

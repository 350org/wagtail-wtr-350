{% load i18n wagtailcore_tags wtrx_tags %} {% comment %} value.width sets the inner content column's measure — see SECTION_WIDTH_CHOICES for why the section owns this rather than each child block. "default" (max-w-6xl, 1152px) is the historical behaviour and stays the default; "narrow" is Figma's 800px reading column for a text + accordion stack; "wide" is its 1266px media band. The heading of a section and everything under it share this one column, so a narrow accordion inside a default-width section would sit ~176px right of the heading above it — which is exactly what "Get the full picture." looked like before this field existed. The fill comes from the shared background palette (.wtr-bg-{color} in main.css), the same one the callout, feature panel, hero banner and signup panel draw from. The fill is an inset rounded panel, not a full-bleed band: the outer wrapper is `max-w-[1500px] mx-auto px-4 sm:px-6 lg:px-8` — the exact class combination image_block.html and the nav (header.html) use — so a section's coloured edge lines up with an ImageBlock's photo edge above or below it, and it carries the same rounded-lg. It used to have its own five-entry list (light/dark/primary/secondary/muted) built out of raw Tailwind colour utilities; `background_key` maps those old stored values onto the palette's keys so content saved before the merge still renders. data-bg carries the resolved colour and data-bg-tone the light/dark question, so a child block that needs to invert (text_block.html's prose) asks the tone once instead of naming every dark colour in the palette. {% endcomment %} {% with bg=value.background|background_key on_light=value.background|background_is_light %}
{% comment %} The max-w values are border-box (Tailwind's preflight sets box-sizing globally), so the gutters have to be counted into them for the *content* column to land on Figma's number: 1266px of video needs max-w-[1330px] against lg:px-8. "narrow" instead drops the large-screen gutter entirely — an 800px column already sits ~112px inside a 1024px viewport, so the gutter would only shave the measure without ever preventing an overflow. {% endcomment %}

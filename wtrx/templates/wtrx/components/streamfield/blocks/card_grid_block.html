{% load i18n %} {% comment %} `rows` (from CardGridBlock.get_context) is a list of lists of cards, each sized via _balanced_rows() (wtrx/blocks/__init__.py, max_per_row=3) — never a lone card on its own row, for any card count. Flexbox with justify-center, not CSS Grid: each row is its own flex container, so a partial row (e.g. 2 cards) centers naturally, matching the same dynamic-centering technique PersonCardGridBlock/ImageGridBlock/ LogoGridBlock use. md:, not sm:, is the row-split breakpoint — cards carry more content (image, heading, description, tag, link) than a person card or a logo, so they need more room before splitting into multiple columns. Heading size/alignment matches the same left-aligned display-heading convention as CardCarouselBlock/ImageCardListBlock's own section headings (font-heading ... lg:text-5xl) — per Figma's "Areas of work", which is left-aligned, not centered. Figma draws this step at 96px (text-8xl); the whole non-hero ramp was brought down against a 20px body, so it is 48px here — see the type scale note in AGENTS.md. Width: special-cased in content_page.html/home_page.html/post_page.html (alongside page_cards/section/card_carousel/etc.) to skip the shared body column, and owns the same w-full-outer / max-w-inner pair PageCardsBlock uses — max-w-[1218px], Figma's card row width. The two blocks are the same thing visually (a row of cards under a display heading), so a CardGridBlock sitting above or below a PageCardsBlock has to line its card edges up with it. As in page_cards_block.html, the 1218px cap has to be the ONLY max-w/padding pair on its own element, not stacked with the outer gutter's padding — otherwise the gutter subtracts from 1218 rather than just giving the row mobile-edge breathing room. {% endcomment %}

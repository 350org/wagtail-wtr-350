No anchor is server-rendered: the inline script below inserts it once the visitor's country is known via Cloudflare's /cdn-cgi/trace edge endpoint (never reaches Django, so it can't poison the page cache). Fundraise Up replaces an anchor with its form the moment it finds one and also picks up anchors added later, so an anchor rendered up front was usually hydrated with the default form before the lookup returned, and changing its href afterwards did nothing. The default form is inserted instead if the lookup fails (no Cloudflare in front, e.g. staging or local dev) or takes longer than LOOKUP_TIMEOUT_MS. `?fundraiseup_country=GB` on the page URL skips the lookup, for checking each region's form without a VPN. wtr-donate-fundraiseup scopes the script to its own wrapper via document.currentScript, the same convention _actionkit_form.html uses, so a page carrying more than one of these blocks wires each one independently. {% endcomment %}

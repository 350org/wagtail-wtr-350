{% load i18n wagtailimages_tags %} {% comment %} `rows` (from LogoGridBlock.get_context) is a list of lists of logos, each sized via _balanced_rows() (wtrx/blocks/__init__.py, max_per_row=5) — never a lone logo on its own row, for any logo count. Flexbox with justify-center, not CSS Grid: each row is its own flex container, so a partial row centers naturally, the same dynamic-centering technique CardGridBlock/PersonCardGridBlock/ImageGridBlock use. Denser cap and a fixed-height cell (object-contain) than ImageGridBlock — logos are small marks of mixed aspect ratio, not uniform photos, so they need to align on a common baseline rather than crop to fill a shape. Alt text follows the non-image-fallback pattern (AGENTS.md pitfall #38): image.description|default:logo.name, not bare rendition alt — a logo's fallback is an organization name, not a filename/description chain. Full-bleed width: same w-full-outer / max-w-inner two-tier pattern as image_grid_block.html. {% endcomment %}

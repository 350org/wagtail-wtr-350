A flat list of external links to other regional 350.org sites — the same list on every page regardless of any footer override, since it isn't itself region-specific content (see FooterSettings.regional_sites). Opens a native modal (RegionalSiteModal, static/js/components/ regional-site-modal.js) rather than a hover dropdown — easier to reach on touch, and doesn't rely on hover for discovery. showModal() gives us Escape-to-close and top-layer stacking for free; the JS only needs to wire the trigger, the close button, and a backdrop click. Full-bleed layout (centered title, grid of pin-marker cards, large corner close button) rather than a small anchored popover — modelled on a location-switcher reference the design gave, minus the region groupings that reference has. border-2 on both card grids below, matching every other card-shaped component on the site (components/card.html, post_card.html, person_card.html, image_card_list_block.html). Most entries are plain regional sites (just a region name) and render in the dense 4-column grid. An entry with `description` set (e.g. "350 Action", "350 Global" — sites that aren't a regional 350.org site and need a line of context) instead renders in its own 2-column row below, since the extra text needs more room than the dense grid's cards give it. Two passes over the same `regional_sites` list rather than a Python-side partition — the split is a single boolean check, not worth a get_context() this include doesn't otherwise need. data-regional-sites-trigger is scoped to its own .wtr-regional-site-switcher ancestor (not a page-wide id lookup) the same way _actionkit_form.html's script scopes itself — this partial is included from two mutually exclusive footer layout branches (minimal vs columns) today, but scoping per-instance means a future third call site on the same page still works correctly.
